## pongrabbit-MD 1.0.3 — 多窗口，多灵感

> **右键即开，一稿一窗。** 资源管理器里选中 Markdown，用 pongrabbit-MD 打开——每个文件各自独立窗口，对照写作、查阅资料，桌面级节奏终于跟得上你的思路。

### 下载

- **Windows**：`pongrabbit-MD Setup 1.0.3.exe`（安装版，推荐）、`pongrabbit-MD 1.0.3.exe`（便携版）
- **macOS**：`pongrabbit-MD-1.0.3.dmg` / `.zip`（若维护者已上传对应平台构建）

### 本版必试

| 功能 | 你会爱上它的理由 |
|------|------------------|
| **多窗口打开** | 右键不同 `.md` 文件，各开各的窗，互不打扰 |
| **智能聚焦** | 同一文件已打开？自动跳到那个窗口，不会重复开两份 |
| **新建可选新窗** | `Ctrl+N` 询问「新窗口 / 当前窗口」，灵感来了就新开一桌 |
| **配置一处生效** | 主题、字体、工作区全局共享，多窗但不割裂 |

### 说明

- 本版本 **未做 Apple / Windows 代码签名**；首次运行请按系统提示选择「仍要打开」或通过右键打开。
- Mac 默认制品为 **x64**；M 系列 Mac 可使用 Rosetta，或自行从源码构建通用包。
