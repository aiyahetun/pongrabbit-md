# pongrabbit-MD v1.0.32 发布说明

**日期**：2026-09-29

## 重要（Mac 用户）

- **本版 Mac 安装包为通用包（Universal）**：**Intel 芯片** 与 **Apple 芯片（M 系列）** 均可安装运行。
- 若你在 **Intel Mac** 上安装 v1.0.31 及更早版本打不开，请 **下载本版** 的 `.dmg` 或 `.zip` 重新安装；授权码无需更换。
- macOS 未做苹果公证：首次被系统拦截时，请在访达中对应用 **右键 → 打开**。

## 变更

- 修正 GitHub Release 的 Mac 构建方式：由仅 Apple 芯片架构改为 **Universal** 打包。
- 功能与 v1.0.31 相同（爱发电购买链接、14 天试用、离线授权、中英界面）。
