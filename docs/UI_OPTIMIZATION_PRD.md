## 1. 背景与目标

pongrabbit-MD 已具备多模式编辑、三主题、工作区、文档目录、导出与音效等完整能力。当前 UI 的主要问题是：

1. **横向空间不足**：工作区（220px）+ 文档目录（200px）并列，挤压编辑区。
2. **顶栏信息过载**：保存与 4 种导出入口同级展示，窄窗需横向滚动。
3. **目录能力不完整**：无滚动高亮、无章节折叠，长文导航效率低。
4. **阅读排版**：预览区强制两端对齐，中英文混排可读性欠佳。
5. **无障碍基础弱**：格式工具栏大量按钮缺少 `aria-label`。

**产品目标**：在不大改技术栈的前提下，提升写作区宽度、降低认知负担、完善目录导航，并为后续视觉升级（无分割线、图标统一）铺路。

**成功指标（定性）**：

- 默认窗口（1100×720）下编辑区可视宽度增加 ≥ 15%。
- 顶栏主操作区按钮数减少 ≥ 3 个（导出合并）。
- 长文档（≥ 10 个标题）目录点击与滚动双向同步。

## 4. Phase 1 功能需求

### 4.1 左侧导航 Tab 合并（P0）

**现状**：`#sidebar`（工作区）与 `#doc-outline`（目录）横向并列，合计约 420px。

**目标**：合并为单一 `#sidebar`（宽度 240px），顶部 Tab 切换：

| Tab | 内容 |
|-----|------|
| **目录**（默认） | `#outline-list`，h1–h3，点击跳转 |
| **文件** | 工作区路径、文件树、新建、最近打开 |

**交互**：

- Tab 切换不折叠整个侧栏；侧栏折叠按钮行为不变。
- 当前 Tab 写入配置 `sidebarTab: 'outline' \| 'files'`，下次启动恢复。
- 「文件」Tab 下显示原工作区工具按钮（选择文件夹、刷新）；「目录」Tab 下隐藏。

**验收**：

- [ ] 仅存在一个左侧面板，宽度 240px
- [ ] 切换 Tab 内容正确，配置持久化
- [ ] 侧栏折叠 / 展开与现有一致

---

### 4.2 目录增强（P0）

#### 4.2.1 Scroll Spy

- 用户滚动编辑区 / 预览区时，目录自动高亮当前章节。
- 实现：`IntersectionObserver`，`root` 为当前模式滚动容器，`rootMargin` 顶部偏移约 80px。
- 用户点击目录跳转后 800ms 内暂停 Spy，避免滚动动画期间抖动。

#### 4.2.2 章节折叠

- 含三级标题的二级标题前显示折叠钮（▾/▸）。
- 折叠后隐藏其下所有 h3 目录项，直至展开。
- 折叠状态仅会话内保持（不持久化）。

**验收**：

- [ ] 预览 / 可视化 / 源码 / 分栏四种模式下 Spy 可用（源码模式按行号区间估算）
- [ ] h2 折叠不影响 h1、h2 自身显示

---

### 4.3 顶栏导出分级（P0）

**现状**：`导出 PDF`、`导出 HTML`、`短图 3:4`、`长图 3:4` 四个并列按钮。

**目标**：合并为 **「导出 ▾」** 下拉菜单，保留原 `id` 与快捷键逻辑。

```
导出 ▾
  ├ 导出 PDF
  ├ 导出 HTML
  ├ ─────────
  ├ 短图 3:4
  └ 长图 3:4
```

**交互**：

- 点击「导出」展开/收起；点击外部或 Esc 关闭。
- 只读文档时菜单项 `disabled`（与现逻辑一致）。

**验收**：

- [ ] 顶栏 `#mode-actions-scroll` 减少 3 个可见按钮
- [ ] 四项导出功能行为不变

---

### 4.4 预览排版（P1）

- `#preview-content` 默认 `text-align: start`（取消强制两端对齐）。
- 设置面板增加「预览两端对齐」开关，配置项 `previewJustify: boolean`，默认 `false`。

**验收**：

- [ ] 新安装默认左对齐
- [ ] 设置开关可切换并持久化

---

### 4.5 无障碍：格式按钮 aria-label（P1）

为富文本与 Markdown 工具栏主要 `fmt-btn` 补充 `aria-label`（与 `title` 一致或更完整）。

**验收**：

- [ ] 主要格式按钮均有 `aria-label`
- [ ] 不影响现有 `title` 提示
