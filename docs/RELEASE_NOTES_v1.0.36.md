# pongrabbit-MD v1.0.36 发布说明

**日期**：2026-10-06

## 变更

- **撤销体验**：连续打字合并为一步；**500ms** 停顿或 **标点/空白** 后分段；插表、粘贴、格式按钮仍为独立一步（约 150 次可撤销操作）。
- **插入表格**：对话框确认后不再跳回文档顶部（保留滚动位置）。
- **毛玻璃主题**：无壁纸时文本选中高亮与背景对比度提升。
