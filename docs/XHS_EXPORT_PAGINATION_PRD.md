## 1. 背景与问题

pongrabbit-MD 支持将 Markdown 导出为小红书风格短图（3:4 多页）与长图（单张竖图）。当前实现基于 **html2canvas** 离屏渲染，存在三类用户可见问题：

### 1.1 长图无法承载过长文档

- 单张长图输出高度硬上限 **32,000 px**（宽约 2160 px），超出即报错中止。
- 另有按字符数的保守分段上限（标准 9,000 / 舒适 5,500 / 加大 3,500），与真实排版高度脱节。
- 无 `##` 标题的长文只能整篇渲染，极易触顶失败。

### 1.2 短图分页切半行、各页高度差异大

- 旧流程：整段 Markdown → 一张超高 canvas → 按固定 **2880 px** 等距像素切片。
- 切片线落在行中间，出现「一行文字切成两半」。
- 末页常只有半页内容，各页视觉高度不一致。

### 1.3 字号偏小，不适合社交媒体阅读

- 标准档版心正文仅 **20 px**（导出图按 1080 px 宽显示时等效约 20 px）。
- 行业推荐（小红书/微博/朋友圈）：正文 **36–60 px**（1080 px 宽画布）。
- 当前最大档（加大）约 38 px，仍低于推荐下限。

---

## 2. 目标

| 目标 | 成功标准 |
|------|----------|
| 短图不再切半行 | 分页断点落在块级元素边界（p / h1–h4 / li / pre / blockquote / table / img） |
| 短图页高一致 | 每页输出固定 **2160×2880 px**，不足处底部留白 |
| 长图可续页 | 超高文档自动拆为多张长图（`标题-01.png`、`标题-02.png`…），不再报错 |
| 社交媒体可读 | 标准档正文提升至约 **34 px**，舒适/加大相应上调 |
| 分页策略可选 | 智能分页（默认）、按 `##`、按 `##`+`###` |

**非目标（本版不做）**：导出前缩略图预览、手动拖拽调断页、字号滑动条、多平台尺寸预设。

## 3. 用户与场景

| 角色 | 场景 | 诉求 |
|------|------|------|
| 小红书博主 | 长文笔记拆成轮播图 | 每页字号够大、不断行、页尺寸统一 |
| 知识分享者 | 整篇导出一张长图 | 超长文自动续页，无需手动加标题 |
| 章节型作者 | 文档有 `##` / `###` | 可按标题语义分段后再分页 |
| 普通用户 | 一键导出 | 默认「智能分页」即可，无需理解技术细节 |

## 4. 方案设计

### 4.1 核心：DOM 块级智能分页

**旧流程**

```
Markdown → 渲染整段 DOM → html2canvas 超高图 → 固定像素盲切
```

**新流程**

```
Markdown → 渲染整段 DOM → 展开表格为行级单元 → 测量块高度 → 按页高分组 → 每组克隆 DOM 单独截图 → 短图垫满 3:4 / 长图按高度续页
```

#### 分页算法（`paginateXhsSurfaceBlocks` + `xhsFlattenPaginationUnits`）

1. 取 `surface` 下直接子节点（排除 `<style>`）作为块；**`table` 按 `tbody tr` 拆成行级单元**。
2. 用 `getBoundingClientRect` 测量每块/每行相对 surface 的 `top` / `bottom`。
3. 可用内容高度 = `1440 - paddingTop(52) - paddingBottom(动态)` layout px，并乘 **0.94** 安全余量。
4. 顺序累加块/行，超过可用高度则在**上一单元边界**换页。
5. 短图渲染后若 `scrollHeight` 仍超版心，**自动把尾部单元移到下一页**（`xhsRenderShortPageChunk`）。
6. 相邻同源表格行在同一页内合并为一张表（带表头重复）。

#### 短图输出

- 每页独立 `html2canvas`，宽度归一化至 **2160 px**。
- 高度不足 **2880 px** 时底部填充背景色至满页。
- 每页右下角签名 `pongrabbit-md`。

#### 长图输出

- 可用内容高度上限 = `floor(32000 / 2) - padding` ≈ **15,900 layout px**。
- 超过则按 DOM 分页拆为多张长图，自动命名 `所选名-01.png`、`所选名-02.png`…
- 不再因超高单张报错（除非单块元素自身超过上限，此时独占一张并提示）。

### 4.2 字号调整

| 档位 | 旧版心字号 | 新版心字号 | 倍率 |
|------|-----------|-----------|------|
| 标准 | 20 px | **34 px** | 1.0 |
| 舒适 | 29 px | **42 px** | 1.24 |
| 加大 | 38 px | **50 px** | 1.47 |

基准常量 `XHS_EXPORT_BASE_FONT_PX`: 20 → **34**。

### 4.3 Markdown 分段策略（导出对话框可选）

| 模式 id | 名称 | 行为 |
|---------|------|------|
| `smart` | 智能分页（默认） | 整篇 Markdown 一次渲染，仅 DOM 分页 |
| `h2` | 按 `##` 分段 | 先按二级标题拆段，每段内 DOM 分页 |
| `h2h3` | 按 `##` / `###` | 先按二三级标题拆段，每段内 DOM 分页 |

配置项 `xhsExportPagination`，持久化至用户 config。

### 4.4 字符上限调整

智能模式下不再依赖字符硬切。`h2` / `h2h3` 模式保留段落兜底拆分，上限放宽：

| 档位 | 旧上限 | 新上限 |
|------|--------|--------|
| 标准 | 9,000 | 50,000 |
| 舒适 | 5,500 | 35,000 |
| 加大 | 3,500 | 25,000 |

## 6. 技术约束

| 项 | 说明 |
|----|------|
| 渲染引擎 | html2canvas 1.4.1，scale=2 |
| 版心尺寸 | 1080×1440 CSS px |
| 输出尺寸 | 短图固定 2160×2880；长图宽 2160、高随内容（单张 ≤32000 px） |
| 浏览器画布极限 | Chromium 单边约 32767 px，保留 32000 安全余量 |
| 编辑器字号 | 不受影响，仅导出层 |

## 7. 验收标准

### 7.1 短图

- [ ] 含 5+ 段纯文字文档导出，任意页无「半行切断」
- [ ] 所有短图输出尺寸均为 2160×2880
- [ ] 末页仅有少量文字时，文字在页面上方，下方为背景留白（非切字）
- [ ] 各页正文字号肉眼明显大于旧版标准档

### 7.2 长图

- [ ] 无 `##` 的 1.5 万字文档可成功导出（自动续页为多张）
- [ ] 续页文件命名连续：`标题-01.png`、`标题-02.png`
- [ ] 单张长图不再出现「超过高度上限」报错（正常图文混排）

### 7.3 分页策略

- [ ] 默认「智能分页」整篇导出，断页在段落边界
- [ ] 「按 ##」时每个二级标题区块独立成组，组内再分页
- [ ] 用户选择写入 config，下次导出记住

### 7.4 回归

- [ ] 六种配色、四种字体正常
- [ ] 代码块、表格、图片、引用块导出无错位
- [ ] 签名仍出现在每张短图及每张长图右下角

## 8. 风险与已知限制

| 风险 | 缓解 |
|------|------|
| 单块超高（如 200 行代码）短图仍可能一页放不下 | 独占一页，内容区可超出版心，底部垫白至 2880；后续版本可考虑按行拆 pre |
| 大文档一次渲染内存占用 | `h2` 模式可分段渲染降低峰值 |
| html2canvas 高度测量偏差 | 保留行高 2.12、CJK 字距与 paddingBottom 防裁切 |
