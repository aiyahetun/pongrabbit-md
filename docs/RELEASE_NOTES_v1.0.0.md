## pongrabbit-MD 1.0.0 — 首发 · 会呼吸的 Markdown 桌面

> **把灵感写成作品**——毛玻璃、环境音、工作区与四模式编辑，沉浸式写作桌正式登场。

### 下载

- **macOS（Intel x64）**：`pongrabbit-MD-1.0.0.dmg`（推荐）或 `pongrabbit-MD-1.0.0.zip`
- **Windows**：`pongrabbit-MD Setup 1.0.0.exe`（安装版）、`pongrabbit-MD 1.0.0.exe`（便携版，若已上传）

### 亮点

- 浅色 / 深色 / **毛玻璃**主题，支持自定义壁纸、模糊与遮罩调节  
- **壁纸与文字对比**（浅色毛玻璃 / 深色毛玻璃 / 自动）  
- 工作区侧栏：选择文件夹、树形浏览、新建笔记与文件夹  
- 音效与音乐：环境音预设 + 本地音乐文件夹  
- 多模式编辑：可视化、Markdown、预览、分栏  
- 导出 PDF / HTML  

### 说明

- 本版本 **未做 Apple / Windows 代码签名**；首次运行请按系统提示选择「仍要打开」或通过右键打开。  
- Mac 默认制品为 **x64**；M 系列 Mac 可使用 Rosetta，或自行从源码执行 `npm run build-mac-universal` 生成通用包。
