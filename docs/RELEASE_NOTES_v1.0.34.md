# pongrabbit-MD v1.0.34 发布说明

**日期**：2026-10-03

## 变更

- **表格编辑**：可视化表格内输入内容后，在「可视化 ↔ 源码」间切换，单元格内容保持在原行，不再在表格下方多出错行。
- **模式切换性能**：长文下可视化 / 源码 / 预览切换明显加快（避免重复全量解析与 O(n²) 光标定位）。
- **撤销性能**：Ctrl+Z / Ctrl+Y 响应与文档长度更匹配，不再长时间无响应。
- **字数统计**：状态栏「字数」「字符」规则优化——中文按字计；英文按词计字数、按字符计字符数（不计空格与换行）。
