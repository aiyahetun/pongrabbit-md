## pongrabbit-MD 1.0.2 — 更好写，更好看，更好导

> 从编辑手感到导出成品，一整条创作链路打磨到位——**写得顺、看得清、发得出去。**

### 下载

- **Windows**：`pongrabbit-MD Setup 1.0.2.exe`、`pongrabbit-MD 1.0.2.exe`（便携）
- **macOS**：`pongrabbit-MD-1.0.2.dmg` / `.zip`（若已上传）

### 亮点

- **更宽的写作区**：侧栏目录与工作区 Tab 合并，长文目录 Scroll Spy + 章节折叠。
- **顶栏更干净**：导出收入下拉，主按钮更少、心流更 uninterrupted。
- **右键即达**：编辑区、表格、工作区侧栏完整右键菜单。
- **分栏更聪明**：富文本 ↔ Markdown 切换保留光标；纯文本粘贴不夹带多余格式。
- **只读览代码**：`.json` / `.yaml` / `.py` 等直接打开浏览，需要时再另存为 `.md`。
- **导出更强**：PDF 完整样式；小红书短图/长图修复；疏云素笺配色；超长文自动分页。
- **状态栏路径**：当前文档路径展示 + 一键复制。
