# 右键上下文菜单 — 开发规划

> **状态：已完成**（2026-05-25）  
> 应用目录：`mobimark_source/mobimark`

## 1. 目标

- 编辑区（可视化 / 源码 / 分栏 / 预览只读）与工作区 `#file-tree` 提供右键菜单。
- 表格：表内右键上/下/左/右插行列、删行/列/表；工具栏仅「插入新表」。
- 复用现有 API 与函数，不重复实现工作区 IPC。

## 4. 菜单规格摘要

### 编辑区

- 通用：撤销、重做、剪切、复制、粘贴、全选、查找
- 表格内：上/下/左/右插行列；删行、删列、删表
- 选区：加粗、斜体、删除线、插入链接
- 图片：替换、复制路径、在文件夹中显示、删除
- 链接：打开、编辑、移除
- 代码块：复制代码、删除
- 空白：插入 → 表格/图片/链接/分割线/代码块

### 工作区侧栏

- 文件：打开、重命名、删除、在文件夹中显示、复制路径
- 文件夹：新建笔记/文件夹、重命名、删除、显示、复制路径
- 空白：刷新、新建、更换工作区

## 5. 不在本期

- 合并单元格、表头拖拽、预览内编辑、最近打开列表右键

## 6. 测试建议

1. 可视化模式：表内右键插删行列，撤销。
2. 源码模式：同一表格块 MD 操作后预览一致。
3. 侧栏：重命名/删除当前打开文件、新建笔记。
4. 只读 `.json`：编辑菜单写操作不可用。
5. 重新打包：`windows/build_exe.bat` → 安装 `dist` 内 exe 验证。
