# pongrabbit-MD v1.0.20 发布说明

**日期**：2026-08-30  
**类型**：热修复（P0 回归）

## 修复

### XHS-020 风格设置弹窗被进度条挡住

- **问题**：点「导出短图/长图」后，「导出风格与字体」弹窗仍开着，进度条已叠在最上层，无法改配色/字号/分页，也无法点「继续导出」。
- **原因**：`exportXhsShort` / `exportXhsLong` 在打开设置弹窗**之前**就调用了 `xhsBeginExportSession()`；进度层 z-index 260 高于设置弹窗 200。
- **修复**：进度条延后到用户完成风格选择、目录选择与分段确认之后，再开始分页与渲染。

## 自检加强

- 断言 `openXhsStylePicker` 必须在 `xhsBeginExportSession` 之前
- 冒烟步骤新增：打开设置弹窗时**不应**出现进度条

## 安装包

`mobimark_source/mobimark/dist-1.0.20/pongrabbit-MD Setup 1.0.20.exe`

## 验收要点

1. 点导出短图 → 设置弹窗可正常操作，**无**进度条
2. 点「继续导出」并选目录后 → 进度条出现
3. 冷启动仍无进度条（XHS-018 不回退）
