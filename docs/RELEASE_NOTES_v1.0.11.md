# pongrabbit-MD v1.0.11 发布说明

**日期**：2026-08-30

## 小红书图片导出优化

### 短图智能分页
- 用 **DOM 块级分页** 替代固定像素盲切，分页断点落在段落/标题边界，**不再切半行**。
- 每页固定输出 **2160×2880**，不足处底部留白。

### 长图自动续页
- 超高文档自动拆为多张长图（`标题-01.png`、`标题-02.png`…），不再因高度超限报错。

### 字号提升（社交媒体可读）
- 标准档正文由约 20px 提升至 **约 34px**。
- 舒适档约 **42px**，加大档约 **50px**。

### 分页策略可选
- 导出对话框新增「分页方式」：**智能分页**（默认）、按 `##`、按 `##` / `###`。

详见 [XHS_EXPORT_PAGINATION_PRD.md](./XHS_EXPORT_PAGINATION_PRD.md)。
