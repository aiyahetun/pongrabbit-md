# 上架爱发电

卖这个软件用爱发电的「售卖商品」，标价 ¥58，一次付清。不要建月费会员，也不要开面包多。

爱发电官网写明创作者拿到付款的 94%，平台加支付渠道一共抽 6%。58 元一单，到账大约 54.5 元。以你开通后后台显示的费率为准。

面包多更适合把同一篇文章卖给所有人。一人一个授权码在他们的需求列表里还是投票功能，不是现成的。面包多 Pay 费率更低，但那是支付接口，要自己做下单页，这一期不做。小报童抽成更高，还要粉丝量，不适合。

注册、实名、提现账户只能你本人操作。下面按顺序做。国内商品链接已写入 `mobimark_source/mobimark/src/shared/stores.json` 的 `cn.url`（v1.0.31 起）。改链接后需重新 `npm run release` 并发布安装包。

## 1. 注册并成为创作者

1. 打开 [afdian.com](https://afdian.com/)。打不开就用 [ifdian.net](https://ifdian.net/)，用打得开的那个，不要两个站各注册一次。
2. 用微信登录。手机号按页面要求绑。
3. 点「成为创作者」。主页名字用「彭兔子」或 `pongrabbit`，简介写一句：Markdown 桌面编辑器，Windows 和 macOS。
4. 向导如果逼你先建一个「发电方案」（按月赞助），建一个最低价方案后立刻下架或不要公开。商品页和对外说法都不要提它。有人按月发电，不会收到授权码。

提现要身份证和银行卡，在「设置」或「钱包」里按页面填。这一步不过，钱进得了订单、出不去。

## 2. 上架商品

入口一般是：**设置 → 售卖商品 → 上架新商品**。菜单名字若改过，找「售卖商品」，不要找「发电方案」。

| 项 | 填什么 |
|---|---|
| 名称 | 彭兔子 MD 买断授权（1.x） |
| 价格 | 58 |
| 类型 | 虚拟商品。不要勾选邮寄地址 |
| 发货 | 不要用「兑换码」库存，也不要开「自动随机回复」 |

兑换码和自动随机回复不要一起开，爱发电的创作者指南写过，混用会让同一个人反复领。我们的授权码里写着买家邮箱，必须等对方把邮箱发来再签发，不能提前往库存里堆一批码。

正文粘贴（**商品介绍**整段替换；与授权规则一致，可直接复制到爱发电富文本）：

```text
【这是什么】
彭兔子 MD（pongrabbit-MD）是 Windows / macOS 上的 Markdown 桌面编辑器：多窗口、工作区、毛玻璃主题，以及按页导出小红书 3:4 短图和长图（尽量不从一行字中间切开）。适合已经会写 Markdown、又要发图文的人。

【这一单买到什么】
¥58，一次付费，不是月费。
· 本机激活，离线校验，不需要账号登录写稿
· 含此后 1.x 版本更新（若将来 2.0 另收费，会提前在本商品页说明）
· 同一授权码可在 Windows 与 macOS 上使用（供付款人本人使用）

【试用怎么算】
安装后先试用 14 天，试用期内功能完整。
试用结束后：已有文稿仍可打开、复制；继续编辑、保存、新建、导出（含 PDF / HTML / 小红书图）需要本页购买的授权码。
试用从本机首次启动当天起算 14 个自然日。请安装 GitHub Releases 上的当前最新版（见下）；更早的旧安装包可能没有试用与授权这道限制。

【付款后怎么拿码】
1. 下单时务必填写「常用邮箱」（见页面信息收集）。
2. 若当时没填上，付款后私信我，只发一行邮箱即可。
3. 我会在 24 小时内把授权码发到该邮箱；换电脑凭同一邮箱联系补发。
4. 打开软件 → 设置 → 授权，整行粘贴激活。码很长，请整行复制，勿发到公开群。

【安装包在哪】
爱发电本页只卖授权，不提供安装包下载。
请先打开 GitHub 发布页安装（试用与买断是同一个安装包，区别只在有没有授权码）：
https://github.com/aiyahetun/pongrabbit-md/releases
Windows 选「pongrabbit-MD Setup」安装包；macOS 选 .dmg。装好后先试用，付款后把授权码粘贴进软件即可，一般不必重装。

Windows：若 SmartScreen 提示，点「更多信息」→「仍要运行」。
macOS：未做苹果公证。首次被拦时：访达里对应用右键 → 打开。

【退款与发票】
授权码发出后不退款。重复付款且尚未发码的，7 天内可退多付的一笔。不提供发票。

【重要】
这是买断授权商品，不是微信赞赏，也不是按月「发电」。赞赏 / 按月赞助不会收到授权码。请只通过本商品页 ¥58 购买。
```

如果商品设置里有「收集信息」或「备注」，加一项必填：常用邮箱。

**安装包怎么交付（和商品介绍一致）**  
爱发电商品详情里通常**没有**像网盘那样的「下载区」。买家在付款前就应能从 [GitHub Releases](https://github.com/aiyahetun/pongrabbit-md/releases) 装好软件试用；你发授权码时**不必**再附安装包，除非对方说装不上，再私信发 Releases 链接或网盘。后台若能在「数字内容」里挂 exe/dmg，可以当作付款后的补充入口，但**不要**在商品介绍里写「本页下载」，避免和实际页面对不上。

自动回复（固定的那一条，不是随机）粘贴：

> 已收到。请确认订单备注里有常用邮箱。没有的话，直接回复这封私信，只发一行邮箱。授权码会发到这个邮箱。安装包请从 GitHub 发布页下载（商品介绍里有链接），装好即可试用；收到码后在软件里粘贴激活，无需另买一套。

封面用 [营销](./营销.md) 第 8 张。图还没做之前可以先不传，不要用仓库里的微信赞赏码。

先保存，不要发到微博、小红书或 README。

## 3. 用 1 元走通一单

商品先改成 **1 元**。用另一个微信号买一单（自己的号常常买不了自己的商品）。

看这四件事：

- 钱进了爱发电余额，费率页面上的数字和「大约 6%」差得不多
- 订单号能看见
- 你能给买家发私信
- 备注或私信里能拿到邮箱

有一件做不到，停下来，把差在哪告诉我，不要改去面包多碰运气。

走通之后把价格改回 **58**，再复制商品链接。

## 4. 发码

在 `mobimark_source/mobimark` 下执行，把邮箱换成买家留下的那个：

```text
node scripts/issue-license.js buyer@example.com
```

把输出的整行私信给买家，并写三行：

```text
彭兔子 MD 授权码：
<整行粘贴>

打开软件 → 设置 → 授权，粘贴后点激活。码很长，请整行复制。不要发到群里，里面能解出你的邮箱。
```

订单记在本地表格里，列还是 [收款与发码](./收款与发码.md) 里的那些。平台订单号填爱发电的订单号。

## 5. 链接写回软件

商品确认是 58 元之后，把链接填进 `mobimark_source/mobimark/src/shared/stores.json` 的 `cn.url`，保存并重新打包。设置里选中「国内」且「购买」才会打开这个商品，不会打开赞赏码。

对外发链接之前，先确认对方装的是带授权校验的版本。GitHub 上 v1.0.29 和更早的安装包没有这道锁。
